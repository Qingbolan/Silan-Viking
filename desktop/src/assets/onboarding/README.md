# Workspace onboarding artwork

Generated with the built-in imagegen tool for the approved October 2026 onboarding concept.
These assets ship locally so first-run setup never needs a remote image service.
The application uses its existing Silan icon, not the mockup's placeholder leaf.

Revision: October 5, 2026 — blog-aligned monochrome cutouts.

Edit prompt: Preserve objects and fine pencil texture. Remove the sage circle,
cream backdrop and ground; output real transparent PNG alpha. Render the objects
in neutral black, gray and white, with opaque paper surfaces and clean silhouettes.
All four delivered images have transparent backgrounds. A grayscale CSS filter
normalizes small chromatic variations remaining in generated object pixels.
No blend-mode or background-colored rectangle is used to simulate transparency.

Subject prompts:
- notebook.png: open research notebook, abstract diagrams, graphite pencil, two loose sheets.
- folder.png: light-gray document folder, paper sheets and blank tabs, botanical sprig in a ceramic pot.
- identity.png: manuscript with abstract heading and lines, circular author silhouette, botanical sprig.
